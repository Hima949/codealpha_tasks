Task 2 – LDR Automatic LED Control System

Project Description

This project uses an LDR (Light Dependent Resistor) sensor to automatically control an LED based on surrounding light intensity.

Components Required

- Arduino Uno
- LDR Sensor
- LED
- 220 Ohm Resistor
- Breadboard
- Jumper Wires

Working Principle

When the surrounding light decreases, the LED turns ON automatically. When sufficient light is detected, the LED turns OFF.

Applications

- Automatic street lights
- Smart lighting systems
- Energy-saving applications

Conclusion

This project demonstrates automatic lighting control using Arduino and an LDR sensor.
