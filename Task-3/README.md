Task 3 – Smart Door Lock System

Project Description

The Smart Door Lock System is an Arduino-based project that uses a keypad to enter a password and a servo motor to control the door lock.

Components Used

- Arduino Uno
- 4x4 Keypad
- 16x2 LCD Display
- Servo Motor
- Potentiometer
- 220 Ohm Resistor
- Breadboard
- Jumper Wires

Working

1. LCD displays "Enter Password".
2. User enters the password using the keypad.
3. Correct password (1234) displays "Access Granted".
4. Servo motor rotates to unlock the door.
5. Wrong password displays "Wrong Password".

Password

1234

Simulation

The project was designed and tested using Tinkercad Circuits.

Result

The Smart Door Lock System successfully checks passwords and controls the servo motor.
